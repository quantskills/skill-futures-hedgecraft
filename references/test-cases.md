# Futures Hedgecraft 测试用例

## 用例 1：权益对冲
**提示**: “用沪深 300 股指期货对冲 5000 万权益组合。”
**期望**:
- 从敞口估算对冲比例，而不是凭感觉。
- 说明合约乘数、名义本金和取整处理。
- 加入基差和移仓假设。
**必须包含**:
- 名义本金转换
- 对冲比例逻辑
**必须避免**:
- 直接把权益组合金额复制成合约张数

## 用例 2：Carry 交易
**提示**: “一个商品期货处于 contango，现货价格横盘。”
**期望**:
- 解释展期收益对多头的拖累。
- 区分现货观点和曲线观点。
- 说明 carry 对多头逻辑是帮助还是伤害。
**必须包含**:
- 曲线解释
- 展期收益讨论
**必须避免**:
- 把 contango 当成无关变量

## 用例 3：移仓窗口
**提示**: “近月合约下周到期，成交量已经迁到远月。”
**期望**:
- 给出移仓计划。
- 说明流动性、价差和滑点。
- 避免等到合约难以交易时才处理。
**必须包含**:
- 移仓时点
- 流动性迁移
**必须避免**:
- 在合约基本失去流动性后才移仓

## 用例 4：保证金冲击
**提示**: “只根据预期收益来决定期货多头仓位。”
**期望**:
- 拒绝只看收益的 sizing。
- 加入保证金、跳空风险和压力损失。
- 给出风险导向的头寸规模。
**必须包含**:
- 保证金意识
- 压力 sizing
**必须避免**:
- 让主观信心决定杠杆

## 用例 5：价差交易
**提示**: “交易日历价差，而不是单边方向。”
**期望**:
- 解释价差风险和方向风险的差别。
- 检查两条腿各自的合约流动性。
- 讨论双腿执行和滑点。
**必须包含**:
- 价差专属逻辑
- 双腿执行检查
**必须避免**:
- 用单边交易逻辑套价差交易

## 用例 6：交割风险
**提示**: “持有可交割商品合约到临近到期。”
**期望**:
- 提醒交割、通知日和强制退出风险。
- 写清精确退出规则。
- 把交割机制当成核心约束。
**必须包含**:
- 交割规则
- 退出规则
**必须避免**:
- 假装到期日只是理论日期
