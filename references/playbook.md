# Futures Hedgecraft 研究手册

## 默认观察框架
始终回答四个问题：
1. 要对冲或表达的是什么？
2. 哪个合约真正匹配？
3. 移仓时会发生什么？
4. 压力情景下什么最先出问题？

## 合约选择清单
- 底层敞口匹配
- 合约乘数和 tick value
- 流动性和买卖价差
- 保证金要求
- 交割月和通知日规则
- 交易所特定涨跌停或持仓限制

## 对冲计算
- 先把敞口换成名义本金。
- 再计算对冲比例。
- 再按 beta、久期、DV01 或商品相关性调整。
- 最后检查四舍五入后的合约张数是否仍合理。

## 曲线与 carry
- Contango 会悄悄惩罚多头。
- Backwardation 会悄悄奖励多头。
- 展期收益、基差和日历价差不是装饰，它们就是 PnL 的一部分。

## 常见错误
- 忘记合约乘数
- 用现货直觉处理杠杆工具
- 忽略波动放大时保证金上调
- 移仓太晚，连续两次支付流动性成本
- 把所有期货想法都当成方向 alpha，忘了有些只是对冲

## 特色规则
如果一个期货答案没有说清保证金路径、移仓路径和压力路径，就还没完成。
